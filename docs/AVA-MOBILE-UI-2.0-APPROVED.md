# AVA MOBILE UI 2.0 — Approved Design

Status: APPROVED BY AMIR — implementation tracked in this pull request
Approval date: 2026-11-16
Scope: AVA Android mobile application only.

## Visual identity
- Premium, distinctive AVA INFINITY interface.
- Sultan lavender with a soft pink undertone and rose-gold highlights.
- Very dark purple night background with gradient treatment.
- Modern, readable Persian typography.
- Dark mode is the primary visual direction; light mode may be offered as a user-selectable theme.
- Infinity mark is part of the central brand identity.

## Approved interface requirements
- Full visual refresh; the previous plain/simple appearance is not the intended final UI.
- Glassmorphism: translucent glass-like conversation bubbles/cards, controlled transparency, soft layered depth, subtle luminous borders and lavender gradients.
- Rose-gold action buttons/highlights.
- Ava profile image is changeable from the device gallery and can be reset to the default image.
- Profile image presentation/size and visibility should be customizable.
- Personalization includes theme, color/background and, where supported, font size and transparency.
- User preferences persist across app restarts.

## Main mobile areas
- Home: prominent Ava image/identity, welcome, presence/status and quick access.
- Conversation: glass bubbles, conversation history and visible states for speaking/listening/thinking/idle.
- Memory.
- Personality/profile.
- Voice.
- AVA SECRET vocabulary module, open-ended and editable for future vocabulary additions.
- Daily assistant.
- Project control center/console.
- Security and access control.
- Appearance and personalization settings.

## Implementation truthfulness
- Approved design does not mean every module is already functional.
- Keep visual design separate from backend intelligence, persistent memory, voice services and access-control implementation.
- Demo/canned replies must be labelled as placeholders, not a connected AI conversation engine.
- Track each module as implemented, placeholder, pending integration or not yet implemented.
- Desktop AVA PLATFORM work is out of scope for this mobile UI milestone.
